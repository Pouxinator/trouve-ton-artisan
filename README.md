# Trouve ton artisan

Application web permettant de rechercher des artisans de la région Auvergne-Rhône-Alpes par catégorie ou par nom, de consulter leur fiche détaillée et de les contacter via un formulaire.

## Technologies utilisées

### Frontend
- React
- React Router
- Bootstrap
- Sass
- Axios
- React Helmet Async

### Backend
- Node.js
- Express
- Sequelize
- Nodemailer

### Base de données
- MySQL / MariaDB

---

## Prérequis

Avant de lancer le projet, installer :

- Node.js
- npm
- MySQL ou XAMPP
- Git
